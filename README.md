## 📱 Featured Live Product: HADAR (حضر)
**HADAR** is our enterprise-grade SaaS platform built for educational institutions and tutoring centers:
* **Smart QR Attendance:** Instant millisecond check-in/check-out with duplicate prevention and audio-visual feedback.
* **Offline-First PWA Engine:** Local IndexedDB caching (Dexie.js) allowing scanning inside disconnected classrooms with background auto-sync.
* **Multi-Tenant Scoped Architecture:** Dedicated self-service onboarding (`/register`) and unique center slugs (`/c/[slug]/portal` for students, `/c/[slug]/scanner` for assistants).
* **Financial & Treasury Management:** Student subscriptions, installment tracking, automated receipts, and revenue analytics.
* **Sovereign Super Admin Gate:** Master-key protected administration (`admin@madaar.io`) with platform-wide MRR metrics.

To run HADAR locally:
```bash
npm run dev
# Or
cd HADAAR && npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
